    Le Pacha - Restaurant Website & Custom CMS

    A real one-page website built for a real client - Le Pacha, a Turkish restaurant in Villejuif - with SEO, a reservation call-to-action, and a custom admin panel so the owner can update the menu and opening hours themselves.

    The challenge

    The owner needed a professional site to be found on Google locally and showcase the menu, but couldn't afford a developer every time a dish or price changed.

    My approach

    Designed and built a responsive one-page site (hero, menu highlights, gallery, hours, contact) optimized for local SEO, then built a custom CMS/admin panel from scratch so the client can add, edit or remove menu items, prices and categories, and update opening hours, with no coding needed.

    The result

    Delivered end-to-end as an independent freelance project, live in production and used daily by a real restaurant owner.

    Le Cryptosystème RSA

    Fondements Mathématiques et Analyse de Sécurité

    EncadranteMireille Fouquet
    RecommandationJean-Yves Ducloux
    ÉcoleUniversité Paris Cité · 2025–2026

    This project studies the RSA cryptosystem, one of the most influential public-key algorithms in computing history - from the mathematical foundations (modular arithmetic, Euler's theorem, the Chinese remainder theorem) to key generation, encryption and digital signatures, and a full security analysis covering factorization attacks, the common modulus attack, blinding, and the Bleichenbacher attack on PKCS#1 padding that directly compromised SSL/TLS.
